# Contributing to Awesome Agent SDK

Thank you for your interest in contributing to this curated list! We welcome contributions from the community to help make this the most comprehensive resource for Agent SDKs.

## How to Contribute

### Adding New Entries

1. **Fork the repository** and create a new branch for your contribution
2. **Edit the appropriate section** in [README.md](README.md)
3. **Follow the format**:
   ```markdown
   ### [Project Name](link)
   Brief description of the project (1-2 sentences).
   - **Language**: Programming language(s)
   - **Features**: Key features or capabilities
   - **Best for**: Primary use cases
   ```

4. **Maintain alphabetical order** where applicable within sections
5. **Verify all links** are current and working
6. **Submit a Pull Request** with a clear description of what you're adding

### Guidelines

- **Quality over Quantity**: Focus on SDKs that are well-maintained and widely used
- **Actively Maintained**: Prioritize projects with recent updates and active communities
- **Openly Available**: Include only publicly available SDKs and frameworks
- **Accurate Descriptions**: Be objective and factual in descriptions
- **No Spam**: Don't add projects solely for self-promotion without genuine community value

### Criteria for Inclusion

An SDK/framework should ideally have:
- ✅ Clear documentation
- ✅ Active maintenance and community support
- ✅ Demonstrated real-world usage
- ✅ Open-source or publicly available
- ✅ Relevance to agent development

### Sections Explained

- **Core Agent SDKs**: Major SDKs from AI companies and platforms
- **Language-Specific SDKs**: SDKs organized by programming language
- **Agent Orchestration & Frameworks**: Tools for managing multi-agent systems
- **AI Model Providers**: Services providing AI models for agents
- **Development Tools**: Supporting libraries, hosting, and monitoring tools
- **Resources**: Learning materials, documentation, and examples

## Reporting Issues

Found a broken link or outdated information? Please [open an issue](https://github.com/awesome-agent-sdk/issues) with:
- What needs to be fixed
- Why it's incorrect
- Suggested correction (if applicable)

## Recognition

Contributors will be recognized in commit history and pull requests. Thank you for helping build this resource! 🙌

## Code of Conduct

We are committed to providing a welcoming and inclusive environment. Please be respectful and constructive in all interactions.
